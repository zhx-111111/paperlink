    音乐 · 网易云

    音乐功能（需先打开上方 music_allowed 总开关）走 Meting-API 代理。灰色 / 会员歌曲想取到可播直链，需要在下面填入网易云登录凭证。

    Meting-API 实例地址 music_api（留空用内置默认）
    网易云登录凭证 music_cookie（MUSIC_U cookie）

    获取方法：电脑浏览器打开网易云音乐官网并登录 → 按 F12 打开开发者工具 → Application（应用）→ Cookies → 找到 MUSIC_U，复制它的值粘贴到这里。凭证只保存在你自己的服务器上。

    信纸公开

    勾选 = 所有人可见；未勾选的信纸不显示，但可在「兑换码」里选择发放。

    彩蛋公开设置

    勾选 = 所有用户直接可用；不勾选 = 需在下方「兑换码」里发放。已公开的不进兑换选项。

    兑换码（一码多选 · 可自定义可用次数）

    勾选要发放的彩蛋/信纸（可多选），设置每码可用次数与生成个数。

    生成后单击码框即可整体复制。

    自定义信纸（选色器 / CSS 模板）

    两种模式：① 只用选色器选「信纸颜色 + 笔迹颜色」；② 需要动态信纸、渐变笔迹等效果时， 在下面贴入（或上传）作用于 .page-paper 的自定义 CSS。上传后成为新主题，可在「信纸公开」里控制可见范围。

    模板内预留「信纸代码 / 笔迹代码」两个自定义填写区，填好后在下方贴入或上传即可。
    信纸名称
    自定义 CSS（可选：动态信纸 / 渐变笔迹等；须作用于 .page-paper）
    也可以点击或拖拽上传 .css 文件（≤50KB；粘贴框有内容时以上方为准）

    首页内容（支持 HTML）

    页脚 HTML（首页绿色区域，可无限向下延伸）
    指南 HTML（写一个“?”唤起的页面）
    隐藏浮窗 HTML（连点应用图标 7 次唤起）

    域名验证文件（微信等）

    上传校验文件（如 MP_verify_xxx.txt），站点根路径将原样返回其内容，用于微信等业务域名校验。
